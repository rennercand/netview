# Segurança

- Sessões aleatórias de 256 bits, hashes SHA-256 no banco, validade de 12 horas, cookies HttpOnly/SameSite Strict/Secure em produção. Logout, logout global e revogação. Sem JWT permanente/localStorage.
- Argon2id (64 MiB, três iterações). Login com mensagem genérica, hash dummy para email inexistente, limites distribuídos no Redis. Cadastros pendentes sem acesso; pedidos de acesso não revelam se o email existe. Não há recuperação de senha/MFA nesta fase.
- Mutações exigem Origin exata e token CSRF vinculado à sessão, exceto login/cadastro que ainda exigem Origin e rate limit. API não abre CORS. Requisições same-origin do browser e CLI usam o contrato documentado.
- Autorizações são server-side por associação ativa, papel e permissão. ADMIN global; HOST restrito ao grupo; membro sem upload por padrão. UUID não substitui autorização. Proibição granular de mídia é aplicada inclusive ao gateway.
- Storage privado; nomes originais não viram chaves. Uploads assinados para objeto, parte, tamanho e validade; quotas reservadas atomicamente, ETags/tamanhos conferidos no storage. Não se confia em extensão para declarar mídia reproduzível. FFprobe valida MP4/H.264/AAC; fontes incompatíveis ficam bloqueadas, originais preservados.
- Playback direct: URL de um objeto por 120 segundos; após revogação não há novas concessões. URL já emitida permanece válida até expirar e requests iniciados podem continuar. Não é DRM. Gateway opcional reautoriza cada nova request, inclusive Range; não consegue retirar bytes já recebidos.
- Worker usa subprocessos sem shell, input URL gerado pelo storage conhecido, referências externas MOV desabilitadas, buffers/tempo limitados. Originais não são gravados localmente. Erros de subprocesso com URLs assinadas são substituídos por mensagens genéricas antes de chegar à fila; logs redigem cookies e cabeçalhos. FFmpeg deve receber atualizações da imagem do SO.
- Auditoria registra ator/ação/objeto/resultado, sem IP nem URLs assinadas. Retenção de 30 dias, limpeza pelo worker. Histórico de sessões expiradas é limpo após 30 dias; email, nome e catálogo são mantidos para a biblioteca. Não há implementação ativa de allowlist/denylist IP; tabela reservada não concede segurança extra.
- Swagger somente em desenvolvimento. Banco/Redis/MinIO local presos ao loopback; produção Neon/R2 e rede interna. Segredos, vídeos, backups e `.env*` não entram no Git (exceto exemplo fictício).

Não publique sem configurar HTTPS, segredos exclusivos, backups e retenção do provedor. Não compartilhe logs de storage que incluam query strings assinadas. O operador R2 deve desativar/redigir query strings nos logs de acesso quando aplicável. Reporte vulnerabilidades por canal privado ao mantenedor; não inclua senhas ou objetos privados em issues públicas.
